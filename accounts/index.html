Community playbook

Build
  • Own the integration code in the repos below. Many have a steady queue of “add search provider X” issues.
  • Open harness: publish the test code and query packs (sets of test questions per industry) so developers rerun latency, empty-rate and freshness on their own queries.
  • Migration kit for Google Custom Search and Bing users: a parameter map, a code diff and credits.
Fix first
  • A default API key on the first screen, and the full credit usable at signup.
  • Rate limits for parallel agent calls published, with retry built into the SDK.
  • Speed of the first full-page fetch, so the speed claim holds when page text is included.
Show up
  • GitHub repos: Open WebUI, LangChain, crewAI, AnythingLLM, gpt-researcher, Mastra.
  • Hacker News launches with open numbers. The r/LocalLLaMA and r/OpenWebUI subreddits for self-hosters.
  • Cloudflare's new Web Search API beta, a channel where Exa and Linkup are already launch partners.
Measure
  • MCP and SDK downloads per month (baseline 9.2K and 364K).
  • Merged integration PRs, and repos that list You.com.
  • Signup → first call time, and harness reruns by outside developers.
