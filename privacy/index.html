Web Search API Eval · MCP server and website

Privacy Policy

Last updated October 27, 2026

This policy covers the Web Search API Eval website (psinglap.github.io/websearch-api-eval) and its read-only MCP server (https://websearch-api-eval.psberkeleymba.workers.dev/mcp), used as a connector in Claude, ChatGPT and other AI assistants. Both are run by Pallavi Singla.

What we collect

Nothing that identifies you. The MCP server has no sign-in, no accounts, no cookies and no database. It does not ask for API keys or personal information. The website has no analytics or tracking scripts.

How requests are handled

When your AI assistant calls a tool, the server receives the tool name and its inputs (for example a question ID such as F5 or a provider name), reads the published benchmark data, and returns an answer. The server does not save these inputs, does not log request contents, and never sees the rest of your conversation.

Hosting providers

The MCP server runs on Cloudflare Workers and the website on GitHub Pages. Like any web host, they process standard request data such as IP address and user agent to deliver and protect the service, under their own policies: Cloudflare Privacy Policy and GitHub Privacy Statement. We do not receive, sell or share this data with anyone else.

Retention

We keep no request data. Hosting providers keep their standard operational logs for limited periods under their own policies.

Third-party sharing

None. The server does not call any search API or other external service on your behalf; it only reads the published files on this website.

Children

The service is meant for developers and is not directed at children.

Changes

If this policy changes, the date above will change and the previous version stays in the repository history.

Contact

Questions or requests: open an issue at https://github.com/psinglap/websearch-api-eval/issues.
